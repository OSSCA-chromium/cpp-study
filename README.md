# cpp-study

C++ 책을 함께 공부하고, 배운 내용을 바탕으로 Chromium의 실제 코드를 분석하는 스터디입니다. 각자의 코드, 학습 정리, 이미지, 블로그 링크 등을 PR로 공유합니다.

## 활동 구성

- [books](books/README.md): 스터디에서 학습하는 책별 활동을 모읍니다. 책마다 주차별로 각자의 실습 코드와 학습 내용을 공유합니다.
- [components](components/README.md): 각자 관심 있는 Chromium 모듈을 원할 때 하나씩 분석합니다. 스터디에서 배운 개념이 실제 코드에 어떻게 사용되는지 살펴보고 분석 내용을 공유합니다.
