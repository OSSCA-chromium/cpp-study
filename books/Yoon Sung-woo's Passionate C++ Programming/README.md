# 윤성우의 열혈 C++ 프로그래밍

## 폴더 구조

주차 폴더 안에 자신의 GitHub 아이디로 폴더를 만들고, 공유할 코드나 학습 정리를 넣습니다.

```text
week01/
└── <github-username>/
    ├── README.md
    └── main.cpp
week02/
└── <github-username>/
    └── README.md
```

- 주차는 `week01`, `week02`처럼 두 자리 숫자로 작성합니다.
- `<github-username>`은 자신의 실제 GitHub 아이디로 바꿉니다.
- 파일 이름과 개수는 자유롭게 정합니다. 코드나 정리 중 공유하고 싶은 내용만 올려도 됩니다.
- 필요한 주차와 사용자 폴더는 첫 제출 때 만듭니다. Git은 빈 폴더를 기록하지 않으므로 제출할 파일을 함께 넣습니다.

## PR 올리기

1. 최신 기본 브랜치에서 작업 브랜치를 만듭니다. 예: `study/week01/<github-username>`
2. 이 책 폴더 아래 `week01/<github-username>/`에 공유할 파일을 추가합니다.
3. 자신의 파일을 커밋하고 작업 브랜치를 원격 저장소에 push합니다.
4. 기본 브랜치를 대상으로 PR을 엽니다. 제목 예: `[week01] <github-username> - 포인터 학습 정리`
5. PR 본문에 학습한 내용과 질문 또는 리뷰받고 싶은 부분을 적습니다.

다른 참여자의 폴더를 수정할 때는 PR 본문에 이유를 함께 적어 주세요.
